2. HTML Document Tree

<!DOCTYPE html>
<html>
    <head>
        <title>Page Title</title>
    </head>
    <body>
        <h1>Heading</h1>
        <p>Paragraph</p>
    </body>
</html>
Tag Purpose
<!DOCTYPE html> Declares HTML5 document
<html> Root element
<head> Contains metadata
<title> Browser title
<body> Visible webpage contents
