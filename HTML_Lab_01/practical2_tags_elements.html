  <head>

  </head>
  <body>
    <h1>Heading</h1>
    <p>Paragraph</p>
  </body>
</html>
TagPurpose
<!DOCTYPE html>Declares HTML5 document
<html>Root element
<head>Contains metadata
<title>Browser title
<body>Visible webpage contents

7. Image Tag

The <img> tag is an empty tag with attributes:

  • src - Source path of the image
  • alt - Alternative text if image fails to load
  • width - Width of the image
  • height - Height of the image

8. Anchor Tag

The <a> tag creates hyperlinks.

  • href - URL of the link
  • target - Where to open (_blank = new tab)
