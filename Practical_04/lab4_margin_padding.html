Margin vs Padding Challenge

Box A

padding: 40px

margin: 10px

Box B

padding: 10px

margin: 40px

Observations:

1. Box A has more internal space (padding: 40px).

2. Box B has more external space (margin: 40px).

3. Changing margin does NOT change content position inside border.

4. Changing padding DOES change the position of the content.
